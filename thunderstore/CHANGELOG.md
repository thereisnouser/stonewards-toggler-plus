# Changelog

## 0.2.1

- Release the new global and per-class controls for **both rings and tomes** through the built-in Toggler.
- Support class-specific exceptions to global bans, so an upgrade can be disabled for everyone and enabled only for selected classes (or the reverse).
- Show the game's **original class icons** beside filter names; rename the global filter to **ALL**.
- Use pixel-stepped buttons styled for the Stonewards shop with larger, more legible labels.
- Hide rings that the selected class cannot receive, using the game's native class-validity check. ALL still lists every ring.
- Reduce delays when level-up and pickup rewards are generated by caching reflection metadata and resolving the local player class once per reward draft.
- Preserve existing global game-save blacklists and earlier per-class rule configuration.

## 0.2.0 (development build)

- Add separate class selectors to the Rings and Tomes Toggler categories.
- Let individual classes explicitly enable or disable upgrades, including exceptions to global Toggler bans.
- Keep All classes editing the game's original saved blacklist; store independent per-class ring/tome allow/deny settings in BepInEx.
- Add game-style stepped class buttons with improved label readability.
- Update GitHub and Thunderstore descriptions and prepare the 0.2.0 package.
- Class-based behavior requires in-game verification before publication.

## 0.1.1

- Updated GitHub and Thunderstore descriptions to the shared thereisnouser standard.
- Replaced the Thunderstore icon with the new checkmark-and-plus artwork.
- Kept the restored default ring/tome Toggler behavior from 0.1.0; no gameplay changes.

## 0.1.0
- First public release.
- Add default rings and tomes to the original upgrade Toggler interface.
- Allow vanilla Toggler checkboxes on default upgrades after unlocking Toggler.
- Use the game's original persisted upgrade blacklist and reward filters.
