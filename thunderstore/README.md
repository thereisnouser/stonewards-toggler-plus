# Toggler Plus

Extend the built-in **Stonewards Toggler** to include **default rings and tomes**.

## Features

- Toggle the game's default rings and tomes, not just items purchased with meta currency.
- Uses the original in-game Toggler interface and upgrade cards.
- Uses Stonewards' existing blacklist system, so disabled rings and tomes are excluded from newly generated upgrade choices.
- Keep regular unlockable upgrades and the rest of the Toggler unchanged.
- No separate hotkeys or extra in-game panels.

## How to use

1. Unlock the game's **Toggler** through normal progression.
2. Open the in-game upgrade/unlock shop and locate the rings and tomes.
3. Toggle off any rings or tomes you don't want to receive.
4. Start a new run; the game will exclude your disabled upgrades from newly generated rewards.

Disabled upgrades aren't removed retroactively from an ongoing run. If an upgrade is re-enabled in the Toggler, it becomes eligible for rewards again. Other ordinary game restrictions still apply.

## Compatibility

- BepInEx 5
- Intended for the Stonewards game build used during development
- Uses the existing game save's blacklist data; uninstalling the mod **does not automatically re-enable disabled upgrades**.

**Before uninstalling:** re-enable any default upgrades you want available again.
